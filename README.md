# ナポの幻鉱 -MABOROSHI-

ブラウザで遊べる採掘ゲーム。

https://tanoshiku-programming.github.io/maboroshi/

| キー | |
|---|---|
| 矢印 | 移動 |
| Z | 採掘 |
| X | ハシゴを降りる |
| S | みせ |
| C | 怪しい薬を飲む |
| M | BGM の切り替え |
| R | もう一度（クリア後） |

スマホのブラウザでは、画面に出る仮想パッドで遊べます。

Pyxel（MIT License）を使っています。→ [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md)
